Консольний калькулятор на C#, який використовує алгоритм сортувальної станції Дейкстри (Shunting-yard algorithm) та обчислення через стек для розбору й виконання математичних виразів.

## Особливості
- **Пріоритет операцій:** коректне виконання множення та ділення перед додаванням і відніманням.
- **Дужки:** підтримка вкладених круглих дужок `()` будь-якого рівня складності.
- **Дробові числа:** повноцінна робота з числами з плаваючою точкою.
- **Інтерактивний режим:** нескінченний цикл роботи з можливістю вводити нові приклади поспіль (для виходу введіть `exit`).
- **Обробка помилок:** перехоплення виключень при діленні на нуль та синтаксичних помилках у виразі.
